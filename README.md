# ADNOC / Fertiglobe — Transaction Valuation & Deal Economics

## Overview
Independent M&A and valuation case study on ADNOC's acquisition of OCI Global's controlling stake in Fertiglobe. The project is based entirely on public information and independently modeled assumptions. It is not live advisory work, client work, or transaction execution experience.

## Transaction
- **Buyer:** ADNOC
- **Seller:** OCI Global / OCI Fertilizers B.V.
- **Target:** Fertiglobe plc
- **Announcement:** 15 Dec 2023
- **Closing:** 15 Oct 2024
- **Stake acquired:** 50% + 1 share
- **Price:** AED3.20/share
- **Headline consideration:** ~$3.62bn
- **Ownership change:** ADNOC 36.2% → 86.2%
- **Official premium:** 8% to undisturbed share price

## Methodology
The case study was built in eight phases:

1. Business and industry understanding
2. Transaction reconstruction
3. Historical financial model
4. Driver-based 2026E–2030E forecast
5. Current standalone valuation
6. Ex-ante transaction economics

## Deal Economics
The deal analysis resets the clock to 15 Dec 2023 and avoids hindsight. The model estimates:

- base ex-ante standalone value of ~AED2.80/share
- transaction price of AED3.20/share
- acquired-stake standalone value of ~$3.165bn
- purchase consideration of ~$3.620bn
- strategic-value gap of ~$455m
- required company-wide PV benefit of ~$528m if benefits accrue across ADNOC's 86.2% ownership
- modeled company-wide synergy PV of ~$511m
- approximate base deal breakeven NPV
- base 5-year IRR of ~7% and MOIC of ~1.36x

## Key Findings
1. ADNOC paid above base ex-ante standalone value, creating a ~$455m strategic-value hurdle on OCI's acquired stake.
2. ADNOC's existing 36.2% ownership materially changes the acquisition economics because control-created value can accrue across 86.2% post-deal ownership.
3. The required company-wide strategic-value PV falls from ~$911m if only the acquired 50% benefits to ~$528m if benefits accrue across ADNOC's 86.2% ownership.
4. A base synergy framework across procurement, financing, logistics and operating reliability generates ~$511m of company-wide PV, bringing the headline transaction close to breakeven.
5. The transaction outcome is most sensitive to normalized urea pricing, utilization and feedstock economics, not small WACC changes.

## Sensitivities
Key sensitivities include:

- normalized urea price
- ammonia price
- operating utilization
- annual recurring synergy
- WACC / terminal growth
- NCI value
- Sorfert liability treatment

## Limitations
This is an independent public-information case study. Limitations include:

- no confidential SPA
- no internal ADNOC forecasts
- no proprietary earn-out formula
- no detailed ADNOC purchase price allocation
- no confidential synergy guidance
- limited contemporaneous consensus estimates without Bloomberg / Capital IQ
- estimated economic NCI value
- analyst assumptions for normalized commodity prices and synergies
- low-carbon ammonia optionality not separately valued due insufficient public cash-flow support
